# J P Jewellers

A React and Vite informational website for J P Jewellers in Rajkot. Online product listings, prices, cart, checkout, and order history are not provided; contact the showroom for current selection and availability.

## Pages

- Home
- Shop enquiries
- Categories enquiries
- About Us
- Contact Us

## Local setup

```bash
npm ci
npm run dev
```

Build and preview:

```bash
npm run build
npm run preview
```

## Vercel deployment

Import the GitHub repository in Vercel with the Vite framework preset, build command `npm run build`, and output directory `dist`. No environment variables are required. Use Node 20.19+ or 22.12+ (Node 22.x recommended). The app uses hash-based routes and does not require SPA rewrites. The production deployment has not been tested.
